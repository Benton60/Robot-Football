### Tasks

1) Figure out the programming tool-chains for the controller and robot micro-controllers. 

 - 5 hours

2) Get the screens working for debugging - format, properly printed font, screen code should be almost completely finished.

 - 5 hours

3) Learn o-drive configuration, get motors working spinning, be able to test both motors and controllers. Using simple test code to interface with the motors is fine. 

 - 10 hours

4) Verify which components we can reuse and order the ones we need.

 - 6 hours

5) Get the RFM69 915MHz to send packets, this includes creating a packet layout.

 - 15 hours

6) Build the helper functions for interacting with the motors, turning right, turning left, forward, back, etc.

 - 10 hours

7) Get the RFM69 915MHz to receive packets, at this stage only simple helper functions are necessary.

 - 15 hours

8) Set up parity checking, some sort of addressing format (filtering), encryption (maybe) for the RFM69.

 - 15 hours

9) Build mini-networking stack to handle sending/receiving mode switches on the RFM69, parity checking, encryption (possibly), and addressing. "I'm hoping to get a c-like socket implementation working" - Benton

 - 10 hours

10) PCB for controller, PCB for robot

 - 15 hours

11) Pick a chassis design, create prototype copies using a 3D printer - This is to ensure if we end up needing to modify one of the existing chassis we have we don't drill holes in the wrong place or otherwise ruin it.

 - 20 hours

12) Mount the motors/other electrical to a prototype chassis and wire everything up using the PCBs we designed. At this point the robot should move and function.

 - 30 hours

13) Performance test robot capabilities using controllers

 - 10 hours

14) Fix bugs & finalize the design

 - 30 hours

15) 3D print some sort of basic lid-module for the robot, just as an example

 - 10 hours

16) Clean up wiring and finalize robot form to meet Competition requirements

 - 10 hours
